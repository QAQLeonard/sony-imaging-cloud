## 当前状态

- Android App：`0.1.0-preview`，Android 10 及以上。
- 当前实现针对 Sony α7C II／ILCE-7CM2；其他机型尚未宣布支持。
- 已完成 Android 10／15 模拟器、素材转换与本地模拟 SSH 接口验证。
- 真实相机的蓝牙配对、热点连接、SSH、素材写入及重启后的效果仍待实机验收。
- 首次授信与固件安装沿用电脑端流程；App 负责社区与素材更新，不负责首次刷机。

App 为闭源软件。本仓库仅维护文档，不包含 App 或机内实现源码，也不包含固件、机身备份、签名密钥或安装包。接口示例用于说明接入方式，不是其他机型已经适配成功的证明。

文档基线：2026-11-05。后续机型是否可用，以明确列出的适配与实机验证结果为准。
